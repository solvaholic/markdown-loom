# Support

:wave: Hiyo! If Markdown Loom leaves you with a question or gets in your way, please open an issue in this repository.

- [Ask a usage question](https://github.com/solvaholic/markdown-loom/issues/new?template=question.yml).
- [Open an issue](https://github.com/solvaholic/markdown-loom/issues/new) for a documentation gap, bug report, or feature request.

The [README](./README.md) and [product specification](./docs/SPEC.md) describe what Markdown Loom currently supports. If they do not answer your question, that is useful feedback too.
